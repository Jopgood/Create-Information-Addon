# 🚀 Release v1.6.0 - Handheld Tank Display

> **New Feature**: Show tank information for tools held in your main hand!

## ✨ What's New

### 🔧 Handheld Tank Display
- **Dual Tank View**: Display both chest armor and handheld item tanks simultaneously
- **Smart Tool Detection**: Automatically detects tank-capable items in your main hand
- **Independent Levels**: Each tank shows its own fuel and water levels separately

### 📱 Enhanced User Interface
- **Position-Aware Rendering**: Tanks automatically adjust layout based on screen position
- **Smart Positioning**: Tool tank renders on left for RIGHT positions to prevent clipping
- **Improved Tooltips**: Separate sections for chest and handheld items with color-coded display
- **Better Visual Hierarchy**: Clear distinction between different tank sources

### 🎯 Screen Position Improvements  
- **Anti-Clipping System**: 16-pixel padding for right-side positions prevents tanks from rendering off-screen
- **Bottom Position Support**: Items render above tanks for BOTTOM positions to avoid screen edge clipping
- **Removed CENTER Position**: Streamlined to four corner positions for better user experience

## 🔧 Technical Improvements

### 🏗️ Code Organization
- **Refactored Rendering**: Split complex rendering logic into focused methods
- **New Helper Methods**: Added `isHoldingFuelCapableItem()` and `isHoldingWaterCapableItem()` 
- **Performance Optimized**: Improved rendering pipeline for dual tank displays
- **Memory Efficient**: Reduced redundant calculations in sprite rendering

### ⚙️ Configuration Updates
- **Default Opacity**: Increased from 75% to 80% for better visibility
- **Default Position**: Changed from CENTER to TOP_LEFT for consistency
- **Scale Awareness**: Padding calculations now respect sprite scale factor

## 🎮 How to Use

1. **Equip a tank item** (jetpack, exoskeleton, etc.) in your chest armor slot
2. **Hold a tank-capable tool** in your main hand (hand drill, etc.)
3. **Enable the overlay** in mod config if not already active
4. **Choose your display mode**:
   - **Simplified Mode**: Visual tank sprites showing fill levels
   - **Detailed Mode**: Text-based tooltips with exact fuel/water amounts

### 📍 Display Behavior
- **Single Tank**: Shows chest tank only when no tank tool is held
- **Dual Tank**: Shows both tanks side-by-side when holding tank-capable tool
- **Smart Layout**: Automatically adjusts positioning to prevent screen clipping

## 🔄 Backward Compatibility

✅ **Fully Compatible**: All existing chest-only functionality preserved  
✅ **Configuration Safe**: Existing config files work without changes  
✅ **Performance**: No impact on single-tank display performance

## 📥 Installation

1. Download the latest `.jar` file from this release
2. Place it in your `mods` folder
3. Launch Minecraft with NeoForge
4. Configure overlay settings in Mod Menu or config files

## 🆕 For New Users

This mod displays fuel and water levels for Create mod tanks directly on your HUD, eliminating the need to constantly check tank levels in your inventory. Perfect for users of [Create: Stuff & Additions](https://www.curseforge.com/minecraft/mc-mods/create-stuff-additions) jetpacks and tools!
