# 🐛 Release v1.6.1 - Config Crash Fix

> **Bugfix**: Stops the "trying to get config values before these are loaded to memory" crash.

## 🐛 What's Fixed

### ⚙️ Config Loading Crash
Some players hit a crash with the message **"trying to get config values before these are loaded to memory"**. This happened because the mod could read (or write) its config values before NeoForge had finished loading the config file into memory — for example during early client ticks or keybind handling.

All config accessors now check whether the config has been loaded first:
- If the config is loaded, values behave exactly as before.
- If it isn't loaded yet, the accessor returns the setting's default value instead of crashing, and writes are skipped until the config is available.

There is **no change in behaviour** once the config is loaded — this purely removes the early-access crash window.

## 🔄 Backward Compatibility

✅ **Fully Compatible**: No config changes required; existing config files work unchanged
✅ **No Visual Changes**: Overlay rendering and settings behave identically once loaded

## 📥 Installation

1. Download the latest `.jar` file from this release
2. Place it in your `mods` folder
3. Launch Minecraft with NeoForge

## 🆕 For New Users

This mod displays fuel and water levels for Create mod tanks directly on your HUD, eliminating the need to constantly check tank levels in your inventory. Perfect for users of [Create: Stuff & Additions](https://www.curseforge.com/minecraft/mc-mods/create-stuff-additions) jetpacks and tools!
