# Changelog

## Version 1.5.0 - Major Platform Migration & Feature Expansion

### 🔧 Platform Migration
- **Migrated from Forge to NeoForge** - Complete rewrite for the new modding platform
- **Minecraft 1.21+ Support** - Updated to support the latest Minecraft versions
- **Improved Performance** - Better integration with NeoForge's optimized systems

### 🎯 Enhanced Item Detection
- **Universal Tank Support** - Now automatically detects ANY wearable item with fuel/water capabilities
- **No More Hardcoded Lists** - Dynamically detects fuel and water tanks using NBT data
- **Broader Compatibility** - Works with jetpacks, exoskeletons, and any future tank-equipped items
- **Future-Proof Design** - Automatically supports new Create Stuff & Additions items

### ⚙️ New Configuration Options
- **Sprite Scale Factor** - Customize the size of tank overlays (0.5x to 5.0x scaling)
- **Overlay Opacity Control** - Adjust transparency from 0-100%
- **Flexible Positioning** - Choose from 5 overlay positions (corners, center)
- **Notification Messages** - Toggle setting change notifications on/off
- **Enhanced Config Comments** - Better descriptions for all configuration options

### 🎨 Visual Improvements
- **Tank Monitor Display** - Updated terminology from "Jetpack" to more generic "Tank Monitor"
- **Proper Scaling System** - Fixed sprite duplication issues when scaling overlays
- **Improved Sprite Rendering** - Better visual quality and performance
- **Consistent Styling** - Unified appearance across all overlay types

### 🔧 Technical Improvements
- **Modern Data Components** - Upgraded from legacy NBT to Minecraft's new data component system
- **Cleaner Codebase** - Refactored for better maintainability and performance
- **Generic Helper Methods** - More flexible utility functions for tank detection
- **Better Error Handling** - Improved stability and debugging capabilities

### 🐛 Bug Fixes
- **🚨 CRITICAL: Server Crash Fix** - Resolved crashes when mod was accidentally installed on dedicated servers (GitHub Issue #1)
- **Fixed Sprite Duplication** - Resolved issue where sprites appeared in 2x2 or 3x3 grids
- **Server Compatibility** - Full multiplayer server support with proper client-server separation
- **Memory Optimization** - Reduced memory usage and improved rendering performance
- **Config Synchronization** - Better handling of configuration changes

### 📝 Documentation
- **Updated Mod Description** - Now reflects broader tank support capabilities
- **Improved Code Comments** - Better documentation for developers and contributors
- **Version Tracking** - Proper changelog maintenance for future updates

---

**For Players:**
- Your existing configs will be automatically migrated
- The mod now works with more items automatically - no manual updates needed!
- Use the new scale factor setting to make overlays more visible on larger GUI scales
- Enjoy improved performance and stability

**For Server Admins:**
- The mod is now built on NeoForge - ensure your server supports NeoForge mods
- Sprite overlays work perfectly on servers
- Tooltip overlays may have some multiplayer limitations (being addressed in future updates)

**Download:** Compatible with Minecraft 1.21+ and NeoForge
